# Restaurant Web Application

A modern, responsive restaurant web application built with React and Vite. This application provides a seamless user experience for exploring restaurant offerings, making reservations, and viewing the menu.

## 🌟 Features

- **Responsive Navigation** - Intuitive navbar for easy navigation across the application
- **Home Page** - Engaging landing page with carousel, about section, and featured content
- **User Authentication** - Complete login and signup system for user management
- **Reservation System** - Book a table with an easy-to-use reservation form
- **Menu Display** - Browse restaurant menu with beautifully presented dishes
- **About Section** - Learn more about the restaurant and its offerings
- **Reviews Section** - Customer testimonials and reviews
- **Featured Items** - Showcase restaurant features and special dishes
- **Contact Page** - Get in touch with the restaurant
- **Responsive Design** - Mobile-friendly layout that works on all devices

## 🛠️ Technologies Used

### Frontend Framework & Tools
- **React** - JavaScript library for building user interfaces with component-based architecture
- **Vite** - Next-generation frontend build tool for faster development and optimized production builds
- **JavaScript (ES6+)** - Modern JavaScript for interactive features

### Development & Code Quality
- **ESLint** - JavaScript linter for maintaining code quality and consistency
- **CSS** - Custom styling for responsive and attractive UI design

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository** (if applicable)
   ```bash
   git clone <repository-url>
   cd restaurant/frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   - Navigate to `http://localhost:5173` (or the URL shown in terminal)

### Build for Production
```bash
npm run build
```

### Run ESLint
```bash
npm run lint
```

## 📝 Available Scripts

- `npm run dev` - Start development server with hot module replacement
- `npm run build` - Build optimized production bundle
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint to check code quality
